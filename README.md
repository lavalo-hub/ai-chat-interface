# AI Chat Interface - ChatGPT Clone

Полнофункциональный интерфейс для AI чата, похожий на ChatGPT, построенный на React + TypeScript.

## 🚀 Особенности

- **Современный UI** - Темный дизайн как в ChatGPT
- **Мультиконверсационность** - Создавайте и управляйте несколькими чатами
- **Выбор моделей** - Переключайтесь между разными AI моделями
- **Поддержка Markdown** - Форматированный вывод с подсветкой кода
- **Система сообщений** - Оценивание и копирование ответов
- **Адаптивный дизайн** - Отлично работает на всех устройствах
- **Сохранение состояния** - История чатов сохраняется локально
- **Анимации** - Плавные переходы и эффекты с Framer Motion
- **Голосовой ввод** - Функция записи сообщений
- **Загрузка файлов** - Поддержка вложений (подготовлено)

## 📋 Требования

- Node.js >= 16.x
- npm или yarn

## 🛠️ Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/lavalo-hub/ai-chat-interface.git
cd ai-chat-interface

# Установите зависимости
npm install

# Запустите dev сервер
npm run dev
```

Апликация откроется на `http://localhost:3000`

## 🏗️ Структура проекта

```
src/
├── components/          # React компоненты
│   ├── Sidebar.tsx      # Боковая панель с чатами
│   ├── ChatWindow.tsx   # Основное окно чата
```

## 🔌 Интеграция с API

Для подключения реального API:

1. Отредактируйте `src/store/apiService.ts`
2. Добавьте ваш API URL:

```typescript
const API_BASE_URL = process.env.REACT_APP_API_URL || 'https://your-api.com/api';
```

3. Обновите функции в `ChatWindow.tsx` для отправки настоящих запросов

## 📝 Использование

1. **Новый чат** - Нажмите "New Chat" в боковой панели
2. **Отправка сообщения** - Введите текст и нажмите Enter или кнопку отправки
3. **Выбор модели** - Используйте ModelSelector в шапке
4. **Управление чатами** - Удалите или переключитесь между чатами в боковой панели
5. **Копирование** - Наведите на сообщение и нажмите иконку копирования

## ⚙️ Конфигурация

Создайте файл `.env` в корне проекта:

```env
REACT_APP_API_URL=http://localhost:3001/api
REACT_APP_API_KEY=your_api_key
```
